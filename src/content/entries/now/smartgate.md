A smart gate that recognises faces and licence plates without needing the internet. Before buying hardware I'm starting with zero-cost bench labs on a Raspberry Pi 4B: how much Linux timing jitters, how fast face detection runs, and tuning a camera-tracking PID loop in software first. The real build is planned for 2028.
